# Great-circle distance in kilometres

Implemented here rather than depending on a geospatial stack for five
lines of trigonometry.

## Usage

``` r
haversine(lon1, lat1, lon2, lat2)
```

## Arguments

- lon1, lat1:

  Coordinates of one point, in degrees.

- lon2, lat2:

  Coordinates to measure to, in degrees.

## Value

Distances in kilometres.
