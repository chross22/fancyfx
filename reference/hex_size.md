# Hexagon size from a bin count, unless given outright

Hexagon size from a bin count, unless given outright

## Usage

``` r
hex_size(x, bins, cellsize)
```

## Arguments

- x:

  Numeric vector of x coordinates.

- bins:

  Approximate number of hexagons across the x range.

- cellsize:

  Explicit size, centre to vertex.

## Value

The size, centre to vertex.
