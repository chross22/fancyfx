# The TSS-maximising threshold, overall or per fold

The TSS-maximising threshold, overall or per fold

## Usage

``` r
best_thresholds(scores, grouped)
```

## Arguments

- scores:

  A
  [`threshold_metrics()`](https://camilleross.org/fancyfx/reference/threshold_metrics.md)
  frame.

- grouped:

  Whether the frame carries folds.

## Value

A one-column data frame of thresholds.
